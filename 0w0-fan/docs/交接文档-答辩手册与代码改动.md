### 4.2 三处最需要注意的地方

**① 核心对比讲的是「对角」，不是「左右」**

我第一版写错了，已修正。正确的讲法：

- **左上** 612 人，均 **3.4 首**，热度 **55.41** ← 少而精
- **右下** 614 人，均 **12.4 首**，热度 **28.21** ← 走量
- 产量 **3.65 倍** → 热度 **0.51 倍**

⚠️ **不要说**「右上和右下差一半热度」——右上 54.97 对右下 28.21 数字没错，
但两者作品数 10.5 vs 12.4 差不多，**构不成"产量涨了热度反跌"的论证**。手册 3.1 节有醒目提醒。

**② 页面有两个"平均热度"，要能解释**

| 数字 | 口径 | 用在哪 |
|---|---|---|
| **42.48** | 主表 32,833 行直接 AVG | KPI 卡片 + 四象限横线 |
| 39.33 | 去重视图 28,356 行 AVG | 不展示，仅参考 |

差异原因：热门歌被更多歌单收录，在明细里出现次数多，所以 42.48 偏向热门歌。
手册 **Q7.5** 专门讲了这题。

**③ 演示顺序不要变**

手册第六节给了 10 步演示脚本。关键是第 4~5 步：
选「热度分档」→ 图表选**环形图** → 平均热度这个度量**消失** → 切回柱状图又出现。

## 五、每个数字的出处（你提问前先查这里）

所有数字都来自实测，不是估的。查询方法：

### 5.1 基础计数

```sql
USE spotify_dashboard;
SELECT COUNT(*) FROM spotify_songs;          -- 32833  主表（歌曲-歌单明细）
SELECT COUNT(*) FROM artist_track_view;      -- 28356  去重视图
SELECT COUNT(DISTINCT track_artist) FROM artist_track_view;   -- 10693
SELECT COUNT(DISTINCT track_album_name) FROM artist_track_view; -- 19744
SELECT ROUND(AVG(track_popularity),2) FROM spotify_songs;     -- 42.48
SELECT ROUND(AVG(track_popularity),2) FROM artist_track_view; -- 39.33
```

### 5.2 四象限（手册第三、四节的所有数字）

```sql
USE spotify_dashboard;
SELECT
  CASE WHEN works >= 5 AND avgPop >= 42.48 THEN '右上 高产高热'
       WHEN works <  5 AND avgPop >= 42.48 THEN '左上 低产高热'
       WHEN works >= 5 AND avgPop <  42.48 THEN '右下 高产低热'
       ELSE '左下 低产低热' END AS quad,
  COUNT(*) AS n, ROUND(AVG(works),1) AS works_avg, ROUND(AVG(avgPop),2) AS pop_avg
FROM (
  SELECT track_artist, COUNT(DISTINCT track_id) AS works,
         ROUND(AVG(track_popularity),2) AS avgPop
  FROM artist_track_view
  WHERE track_artist IS NOT NULL AND track_artist <> 'NA'
  GROUP BY track_artist HAVING COUNT(DISTINCT track_id) >= 3
) t GROUP BY quad;
```

**实测输出**（2026-11-12）：

| quad | n | works_avg | pop_avg |
|---|---|---|---|
| 右上 高产高热 | 635 | 10.5 | 54.97 |
| 左上 低产高热 | 612 | 3.4 | 55.41 |
| 右下 高产低热 | 614 | 12.4 | 28.21 |
| 左下 低产低热 | 625 | 3.4 | 26.72 |

四人数的合计 = **2,486**（与手册一致）。

### 5.3 组合数

不用 SQL，跑这段（在 `0w0-fan` 目录下）：

```bash
python -c "
import io,re
s=io.open('frontend/js/dashboard.js',encoding='utf-8').read()
m=re.search(r'var DIMS = \{(.*?)\n    \};',s,re.S).group(1)
SHARE={'ring','rose'}; ADD={'songs','artists','albums','works','worksTotal','cnt'}
T=R=0
for name,body in re.findall(r'(\w+): \{(.*?)\n        \}',m,re.S):
    ms=re.search(r'measures: \[(.*?)\]',body); ts=re.search(r'types: \[(.*?)\]',body)
    if not ms or not ts: continue
    M=[x.strip().strip(chr(39)) for x in ms.group(1).split(',')]
    TY=[x.strip().strip(chr(39)) for x in ts.group(1).split(',')]
    T+=len(M)*len(TY); R+=sum(1 for t in TY for me in M if not(t in SHARE and me not in ADD))
print('维度',len(re.findall(r'(\w+): \{',m)),'理论',T,'可达',R)
"
```

输出：`维度 8 理论 90 可达 78`
