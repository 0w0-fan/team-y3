## 四、注意到的两点

1. **四象限 y 分割线用主表均值 42.48**（任务文档写死的值），而散点本身按视图口径计算（视图平均热度为 39.33）。两者分母不同，已在 README 与页面标注中写明，未擅自改动。
2. **`artist_favorite` 对 `artist_name` 建了唯一索引**，因此「同一位歌手」不能重复关注；这是任务文档未规定的字段细节，实现时为保证列表不出现重复项而加的，重复提交返回 409 而不是静默插入。
